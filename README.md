# Hojarasca

Plataformas tramposo de navegador ambientado en un bosque de otoño. Todo el juego está en `index.html`: sin imágenes, sin audio externo y sin dependencias.

- 5 mundos con 20 niveles cada uno y la historia «La última hoja».
- Tres personajes: Nuez, Charca y Púa.
- Español, inglés y francés.
- El progreso se guarda en el navegador.
